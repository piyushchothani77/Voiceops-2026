# Demo recording script (target: 90–120 seconds)

## Before recording
- Open the working Colab notebook with the runtime already initialized.
- Confirm the test audio file is available and the Gnani STT/TTS clients are ready.
- Hide API keys, environment variables, personal browser tabs, and unrelated files.
- Use a real test question and show the output generated by the project.

## Suggested sequence
1. **0:00–0:15 — Introduction:** State that VoiceOps is a voice-based support agent for the fictional ZentroMart store. Mention Gnani STT, policy retrieval/RAG, Groq, and Gnani TTS.
2. **0:15–0:35 — Audio input:** Show the customer audio file and the STT transcription of: “कपड़ों को वापस करने के लिए कितने दिन मिलते हैं?”
3. **0:35–1:00 — Grounded answer:** Show the agent answer stating the standard clothing return window is 15 calendar days from delivery, with the 30-day exception only for orders placed 1–15 October 2026. Briefly show pol_returns_v4.md among the retrieved sources.
4. **1:00–1:20 — Audio output:** Play the generated Hindi WAV reply so the evaluator hears the result.
5. **1:20–1:40 — Output trace:** Show the JSON output fields for transcript, reply, reply-audio path, and retrieved chunks.
6. **1:40–1:55 — Safety / limitations:** Briefly mention order details require verification and ticket creation is confirmed only when the official tool reports success.

## Important
- Keep the recording under 2 minutes.
- Use an actual screen recording of the running project; do not fabricate logs or output.
- Do not show or speak API keys. Do not include the dataset archive or private recordings in the public repository.
